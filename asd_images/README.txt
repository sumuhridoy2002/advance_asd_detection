# README - Image Dataset (Autistic and Typical Individuals)

## Description
This dataset contains images of autistic and typical individuals, organized into three main folders for model training, validation, and testing.

## Directory Structure
- **/train/**: Images for model training:
  - `/autistic/` - 1268 images
  - `/typical/` - 1268 images

- **/valid/**: Images for model validation:
  - `/autistic/` - 50 images
  - `/typical/` - 50 images

- **/test/**: Images for model testing:
  - `/autistic/` - 150 images
  - `/typical/` - 150 images

## Image Totals
- Autistic: 1268 (train) + 50 (valid) + 150 (test) = **1468 images**
- Typical: 1268 (train) + 50 (valid) + 150 (test) = **1468 images**
- Overall total: **2936 images**

## Image Format
- Extension: `.jpg`
- Resolution: 224 x 224
- Color: RGB
